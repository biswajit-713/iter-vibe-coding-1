# Product List — Starter

This is the starting point for the **Industry Gurukul: Using AI Coding Assistants** masterclass.

## What this is

A small React app that shows a list of products. That's it — no search, no filter, no tests yet. We'll build the search/filter feature together, live, during the session.

## Setup (please do this before the session)

```bash
npm install
npm run dev
```

Then open the URL shown in your terminal (usually `http://localhost:5173`). You should see a list of 10 products.

## Before you come to the session

- Make sure `npm install` and `npm run dev` both work on your machine — that's all the setup you need.
- Have [OpenCode](https://opencode.ai) installed and working.
